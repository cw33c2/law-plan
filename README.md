# ⚖️ law-plan — 法務長與智慧財產權合規律師

> 米其林 AI 開發軍團中的**「法務長兼食品衛生合規官」**。專門負責圖片版權審查、海量數據採集個資法過濾、開源授權 GPL 感染防禦，以及著作權合理使用評估。確保專案所有素材 **100% 法律安全，絕不踩雷侵權！**

## 📁 倉庫結構

```
law-plan/
├── SKILL.md       ← 主技能文件（四大法律審查模組）
└── README.md      ← 本說明文件
```

## 🛡️ 四大法律防線

1. 📸 **圖片與視覺素材版權審查**：區分 CC0 / Unsplash / Fal.ai AI 生圖的授權等級，嚴禁爬取未授權圖片。
2. 📄 **數據採集與個資法 PII 過濾**：審查 Robots.txt 合規性，自動抹除 Email / 電話等敏感個資，符合台灣個資法與歐盟 GDPR。
3. 📜 **開源授權 GPL 感染防禦**：掃描 `package.json`，防範 GPL v2/v3 強傳染授權混入商業專案。
4. ✍️ **著作權合理使用與 Citation**：評估引用比例，自動生成標準出處標註與 Disclaimer 免責聲明。

## 🚀 如何使用

對 AI 說：
> `law-plan，請幫我的 [專案名稱] 進行版權與法律合規審查。`

調度官 `peo-plan` 收到後，會自動召喚 `law-plan` 法務長登場！
